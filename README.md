RETAIL ANALYTICS MYSQL PRACTICE
-This repository contains practical SQL queries written to analyze a mock retail dataset. It covers fundamental to advanced concepts in MySQL.

Topics Covered:
- DDL & DML: Creating databases, tables, and inserting structured relational data.
- Filtering & Sorting: Using `WHERE`, `ORDER BY`, `DISTINCT`, and `LIMIT`.
- Aggregations: `GROUP BY`, `HAVING`, `SUM`, `AVG`, `COUNT`, `MIN`, and `MAX`.
- Joins: `INNER JOIN`, `LEFT JOIN` across multiple relational tables.
- Subqueries: Single-row and multi-row subqueries.
- Common Table Expressions (CTEs): Single and multiple CTEs for structured data processing.
- Window Functions: `RANK()`, `DENSE_RANK()`, and `OVER(PARTITION BY)`.
